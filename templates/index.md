# ProFont mirror

**Upstream source:** <https://tobiasjung.name/profont/>.

A compact, highly legible monospaced typeface with a slashed zero and distinct
forms for `I`, `l`, and `1`.

This static mirror makes the original ProFont distributions, documentation,
and related files available without relying on a server-side download endpoint.

[Browse downloads](#downloads) · [View the full directory on GitHub]({{ site.downloads_directory_url }}) · [Read the documentation](assets/About_ProFont_Distribution_2.2.pdf)

## About

ProFont began on classic Mac OS and was designed to stay crisp and readable at
very small point sizes. It is particularly useful when many lines of source
code need to remain visible at once.

The mirror includes bitmap and outline versions for classic Mac OS, macOS,
Windows, and Linux/UNIX X Window systems. Compatibility with current operating
systems varies by file format.

### ProFont IIx

macOS-oriented build with the Euro sign and optional fi/fl ligatures:
[DMG](downloads/profontiix.dmg), [ZIP](downloads/profontiix.zip), or

### Mac bitmap with Euro

Bitmap-only Mac build with the Euro sign in all supported sizes except 7pt:
[ZIP](downloads/ProFont-MacEuro.zip) or [7z](downloads/ProFont-MacEuro.7z).

### Windows bitmap

Classic Windows bitmap font files with no outline shapes:
[ZIP](downloads/profontwin.zip) or [7z](downloads/profontwin.7z).

### Windows TrueType

Outline builds for Windows, macOS, and Linux. They are generally best with
font smoothing enabled.

- Tweaked: [ZIP](downloads/ProFontWinTweaked.zip) or [7z](downloads/ProFontWinTweaked.7z)
- Earlier build: [ZIP](downloads/MProFont.zip) or [7z](downloads/MProFont.7z)
- Bold versions: [ZIP](downloads/ProFont-Windows-Bold.zip) or [7z](downloads/ProFont-Windows-Bold.7z)
- Polish version: [ZIP](downloads/ProFont-Polish.zip) or [7z](downloads/ProFont-Polish.7z)

### Linux / UNIX X Window

OpenType bitmap and PCF bitmap options for X Window environments.

- OTB, November 2019: [ZIP](downloads/profont-otb.zip) or [7z](downloads/profont-otb.7z)
- OTB, December 2019: [ZIP](downloads/profont-otb-2.zip) or [7z](downloads/profont-otb-2.7z)
- X11 PCF, newer: [ZIP](downloads/profont-x11.zip) or [7z](downloads/profont-x11.7z)
- X11 PCF, older: [ZIP](downloads/profontlinux.zip) or [7z](downloads/profontlinux.7z)

### Atari TOS lookalike

ProFontJB, an 8pt GEM bitmap font inspired by the original ProFont:

### Sheldon

A separate bitmap programming font for Mac and Windows.

- Windows: [ZIP](downloads/sheldonwin.zip) or [7z](downloads/sheldonwin.7z)
- Mac: [ZIP](downloads/sheldonmac.zip) or [StuffIt X](downloads/sheldonmac.sitx)
